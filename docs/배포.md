# 배포 가이드 — Backend EC2(Docker) + Frontend Vercel + DB MySQL(Docker on EC2)

## 1. 가비아 도메인 구매 + DNS

1. gabia.com 회원가입 → 도메인 검색·구매 (예: `chatapp.co.kr`, `.com` — 연 1~2만원대)
2. My가비아 → DNS 관리 → 구매한 도메인 → 레코드 추가:
   - 타입 `A`, 호스트 `api`, 값 `16.178.2.69`, TTL 300
   - (Vercel용 루트는 Vercel이 안내하는 대로 — 프론트는 `xxx.vercel.app` 그대로 써도 됨)
3. 전파 확인 (수 분~수 시간):
```powershell
nslookup api.구매한도메인
```

## 2. EC2 HTTPS (Caddy, 인증서 자동)

```bash
sudo apt install -y caddy
sudo tee /etc/caddy/Caddyfile > /dev/null <<'EOF'
api.구매한도메인 {
  reverse_proxy localhost:8080
}
EOF
sudo systemctl reload caddy
curl https://api.구매한도메인/api/chat/rooms/open   # [] 나오면 OK
```
이후 보안그룹에서 **8080 인바운드 삭제** (443/80만 유지).

## 3. Vercel (프론트)

1. `C:\chatapp`을 GitHub에 푸시 → vercel.com → Add New Project → Import
2. **Root Directory: `frontend`**, Build `npm run build`, Output `dist`
3. Environment Variables: `VITE_API_URL=https://api.구매한도메인` (끝에 / 없음)
4. Deploy → `https://<프로젝트>.vercel.app` → user1/1234 로그인
